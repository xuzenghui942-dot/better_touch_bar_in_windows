欢迎使用 Swoosh

将光标移到窗口标题栏，然后在触摸板上用双指向右滑动，即可把窗口吸附到右半屏。抬起手指完成，按 Esc 可取消。

  2. 最大化与最小化
  3. 吸附到角落
  4. 最小化或关闭
  5. 五指调整窗口
  6. 切换虚拟桌面或显示器
